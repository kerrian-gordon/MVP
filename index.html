Recruiting Pipeline

Recruiting Pipeline — MVPs

Standalone MVP testers proving out each piece of the recruiting automation pipeline before it's wired into Make. Every scenario shares two rules: dedup-before-write, and visible error logging instead of silent drops.

Scenario 1

Email → Row Parser

Parses a recruiting email into candidate fields and writes (or updates) a tracking-sheet row, with an inline fix-and-save flow for anything that fails to parse.

Built · tested MVP

Scenario 2

Calendar → Interview Matcher

Matches a calendar invite to a candidate by attendee email, with an AI-style name fallback for invites that don't match cleanly.

Built · tested MVP

Scenario 3

Referral Intake Form

Structured internal referral form — no parsing needed, just the same search-before-write dedup check every other scenario uses.

Built · tested MVP

Scenario 4

Morning Digest Generator

Reads today's Tracker state and produces the plain-text Slack summary — new applicants, today's interviews, pending offers. The one scenario that only reads, never writes.

Built · tested MVP
